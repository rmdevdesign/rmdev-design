UI/UX · Figma · Design system

Structurer une maison connectée dans une interface simple

Conception complète d'une application mobile pilotant volets, stores et brise-soleil orientables, depuis le cahier des charges jusqu'au kit développeur.

Résultat : plus de 100 écrans Figma livrés

Le contexte

Le produit devait réunir plusieurs familles d'équipements dans une expérience cohérente, compréhensible aussi bien pour un usage quotidien que pour la configuration initiale.

La mission couvrait l'architecture fonctionnelle, l'interface et la préparation de la passation aux développeurs.

La démarche

  • Atelier de cadrage, personas et parcours utilisateurs.
  • Wireframes basse fidélité pour valider les flux.
  • Maquettes haute fidélité et design system Figma.
  • Création de plus de 40 pictogrammes dédiés.
  • Export DevMode, documentation PDF et visuels pour les stores.

La livraison

Plus de 100 écrans ont été remis avec les composants, variantes et états nécessaires à l'intégration. L'application issue de ce travail est disponible sur les stores.
